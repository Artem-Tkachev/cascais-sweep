# Cascais Sweep — Hack the City, задача #9

Находим брошенные самокаты в Cascais и строим оптимальный маршрут их сбора.

## Как открыть
Двойной щелчок по `index.html`. Сервер не нужен: все данные лежат в `data/data.js`.

## Как пересчитать данные
```
pip install pandas openpyxl geopandas shapely h3 scikit-learn
python detect.py      # поиск брошенных -> data/abandoned.*
python analytics.py   # KPI, сценарии, новые станции -> data/data.js
```

## Файлы
| Файл | Что делает |
|---|---|
| `detect.py` | Зоны 30 м вокруг станций, «стоянки» самокатов, поиск брошенных |
| `analytics.py` | KPI по шестиугольникам H3, профили по часам, кластеры (новые станции), симуляция вечерних рейсов |
| `index.html` | Сайт: карта + маршрут, спрос, эффект, новые станции |
| `data/copy_viagens.xlsx` | **события** самокатов (имя файла перепутано организаторами) |
| `data/copy_cartoes.xlsx` | **поездки** |

## Для кого
Инструмент для **муниципалитета Cascais (Cascais Próxima)**. Бёрд (оператор) сам собирает свои самокаты; если самокат брошен дольше 2 часов и Bird его не убрал, его забирает муниципальный фургон и штрафует оператора. Мы планируем работу этого фургона (подтверждено João Silva, Cascais Próxima, 24.09).

## Методика (для вопросов жюри)
**Брошенный самокат** = стоит дальше 30 м от зоны станции (`station_area` + буфер 30 м в проекции EPSG:3763) дольше 120 минут.

**Время** в данных в UTC → переводим в лиссабонское (Europe/Lisbon).

**Стоянка** начинается `trip_end` / `provider_drop_off` / `trip_cancel` и заканчивается `trip_start` / `decommissioned` / выездом из зоны / `maintenance_pick_up`, **но только если самокат после этого оказался дальше 50 м**. 72% `maintenance_pick_up` — это обслуживание Bird на месте (замена батареи): через минуту `provider_drop_off` в той же точке, самокат остаётся брошенным.

**Фейковые поездки** (< 60 с или < 50 м) отфильтрованы: 12,1%.

**Приоритет** (решение Артёма после ответа João: «главное — длительность, дальше от станции — важнее»):
```
балл = 3·время + 2·далеко_от_станции + 1,5·(1 − шанс_что_заберут_сами) + 1,5·у_остановки
забронирован → 0
```
- время = часы стоянки / 12, максимум 1; далеко_от_станции = метры / 300, максимум 1
- шанс_что_заберут_сами — логистическая регрессия (заряд, расстояние, спрос в месте, час суток), 5-кратная кросс-валидация: 64,9% против 56,9% наугад
- у_остановки = 1 ближе 20 м к остановке TML, плавно до 0 к 40 м
- поломка/батарея не учитываются: это работа Bird

**Маршрут**: отбор по «балл / минуты крюка» (самокаты по пути почти бесплатны), порядок — ближайший сосед + 2-opt, заезды по 18 самокатов (sweep по секторам).

**Симуляция смены**: будни 9:00–18:00, обед 13–14; фургон берёт до 18 самых важных брошенных, объезжает, возвращается (10 мин разгрузка) и планирует следующий заезд по свежей ситуации. Сравнение: как есть (только Bird) / фургон с объездом по порядку / фургон с нашим маршрутом.

**Параметры**: склад 38.736065, −9.386573 (Cascais Próxima); фургон 18 (João: 15–20); смена 9–18. Допущения: обед 13–14, только будни, дорога = прямая × 1,35, 20 км/ч, 3 мин погрузка, 10 мин разгрузка.

## Ключевые цифры (19.08–09.09.2026, 21 день)
- 920 случаев брошенных, ~44 в день, 569 разных самокатов из 1388; одновременно в среднем 49, в пике 76
- простой после 2 ч: медиана 13,6 ч, среднее 26,9 ч, всего 24 791 ч
- 94% заборов и обслуживания Bird — с 6:00 до 14:00 (по Лиссабону)
- **⚠️ 109 случаев: Bird обслужил на месте уже брошенный самокат и оставил его** — ещё в среднем 16,1 ч, всего 6 652 ч простоя (≈ четверть). Основание для штрафов
- **Муниципальный фургон с нашим маршрутом: −55% часов простоя** (среднее 26,9 → 12,1 ч), 29,3 самоката в день
- против объезда по порядку: **+64% собранных самокатов** (29,3 vs 17,9 в день) при **−24% км** (89 vs 117 в день), 3,0 км на самокат вместо 6,5
- 30 брошенных стояли ближе 20 м к остановке: 657 ч
- 8 лучших мест для новых станций покрыли бы только 6% случаев → решение — сбор, а не станции
